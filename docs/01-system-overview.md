## System Purpose
EduSphere is a unified academic management platform designed to centralize core university operations, automate grading workflows, and simplify assignment submissions.

## Target Audience & Roles
- **Student:** View course schedules, download lecture materials, submit assignments, and track grades.
- **Faculty:** Publish course syllabi, set assignment deadlines, evaluate submissions, and export grade rosters.
- **Administrator:** Manage user access control (IAM), assign roles, and monitor system-wide compliance.

## Value Proposition
Eliminates physical paperwork, prevents lost submissions, and provides real-time academic analytics for administrative decision-making.
