# Presentation Assets

This directory contains slide decks and supplementary presentation materials for the EduSphere project defense.

---

## Expected Artifacts

* `edusphere-presentation.pptx` — Primary slide deck covering system goals, architecture, ICT compliance, and interface wireframes for academic review.

---

## Presentation Structure

1. **System Introduction & Scope:** Problem statement, target roles (Student, Faculty, Admin), and core value proposition.
2. **System Architecture:** Component layout (Preact, Go/Node.js, PostgreSQL/MongoDB, Redis, MinIO) and data flow sequence.
3. **UI/UX Wireframes:** Student dashboard and assignment submission interface layouts.
4. **ICT & Standards Compliance:** Security protocols (ISO/IEC 27001, TLS 1.3, GDPR, REST/OpenAPI 3.0).
