# Architecture Diagrams & Schematics

This directory contains high-resolution system architecture diagrams, data flow schematics, and component topologies for the EduSphere system.

---

## Expected Artifacts

* `architecture-diagram.png` — Structural topology detailing the three-tier interaction between the Preact frontend, Go/Node.js API gateway, PostgreSQL/MongoDB data stores, Redis cache, and MinIO object storage.

---

## Technical Specifications

* **Diagram Notation:** Unified Modeling Language (UML) / C4 Model (Level 2: Container)
* **File Format:** PNG (minimum 1920×1080 resolution, transparent background preferred)
* **Source Files:** Draw.io (`.drawio`) or Excalidraw (`.excalidraw`) exports
